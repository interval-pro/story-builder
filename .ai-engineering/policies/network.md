# Network policy

Research may use the internet. The results are never treated as truth on their
own.

## Trust hierarchy

1. Repository and runtime evidence
2. Official documentation
3. Official release notes
4. Issue trackers and discussions
5. Stack Overflow
6. Forums and community sources

Anything below the first tier must be validated against the project's actual
dependency versions, its runtime and its tests before it is used in a review.

Project secrets are never sent to an external service.
